# COSC2669 Case Study – Individual Task 1

This repository contains the analysis notebooks used for COSC2669 Individual Task 1.

## Notebooks

- `online_shoppers_svm.ipynb`  
  Predicts whether an online shopping session will result in a purchase using a Support Vector Machine (SVM).

- `online_retail_kmeans.ipynb`  
  Performs customer segmentation using RFM features and K-means clustering.

## Datasets

The datasets used are publicly available from the UCI Machine Learning Repository:

- Online Shoppers Purchasing Intention Dataset
- Online Retail Dataset
